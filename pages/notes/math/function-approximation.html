0. Basis functions

  • Select one of the basis functions in later sections
\[\hat f(x)=\sum_{k=1}^{M} c_k\,\phi_k(x)\]
  • fit / estimate coefficients
    • Regularized least squares to determine coefficients
\[\min_{\mathbf{c}}\ \sum_{i=1}^{n}\Big(\sum_{k=1}^{M}c_k\phi_k(x_i)-y_i\Big)^2+\lambda\|\mathbf{c}\|_2^2\]

1. Local polynomial：Taylor / Linearization

  • Taylor polynomial
    \[f(x)\approx \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k\]
  • Taylor remainder (Lagrange form 拉格朗日余项) to bound error
\[R_{n+1}(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1},\quad \xi\in(a,x)\]
\[f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+R_{n+1}(x) \]
  • Process: choose expansion point a → compute derivatives ar a → truncate at order n → use remainder to bound error
  • Example: First-order linearization (multivariate)
\[f(\mathbf{x})\approx f(\mathbf{a})+\nabla f(\mathbf{a})^\top(\mathbf{x}-\mathbf{a})\]

2. Global polynomial：Interpolation / Least-squares

2.1 Polynomial Interpolation

  • Process: given samples \((x_i, y_i)\) → build an interpolating polynominal (Lagrange/Newton) → enforce \(\hat{f}(x_i) = y_i\)
  • 也就是得到一个n次的，准确通过n+1个点的拟合；可以理解为开关
  • Lagrange form: one-hot 开关
    \[p(x)=\sum_{i=0}^{n} y_i\,\ell_i(x),\qquad\ell_i(x)=\prod_{\substack{j=0\\ j\neq i}}^{n}\frac{x-x_j}{x_i-x_j}.\]
  • Newton form: layered 开关
    \[p(x)=c_0+c_1(x-x_0)+c_2(x-x_0)(x-x_1)+\cdots+c_n\prod_{j=0}^{n-1}(x-x_j),\]

2.2 Polynomial least squares (design matrix form)

  • Process: choose degree \(d\) → build design matrix (which is the given numbers) \(A\) → solve leat squares → obtain coefficients
  • 最小二乘法
\[\min_{\mathbf{c}}\|A\mathbf{c}-\mathbf{y}\|_2^2,\quad A_{ik}=\phi_k(x_i),\quad(A^\top A)\mathbf{c}=A^\top\mathbf{y}\]

3. Trigonometric / Fourier approximation

\[f(x)\approx a_0+\sum_{n=1}^{N}\big(a_n\cos(nx)+b_n\sin(nx)\big)\]
  • Process: Sample \(f\) (assume periodic) → compute coefficients via integrals or FFT (Fast Fourier Transform) → truncate to \(N\) harmonics → reconstruct \(\hat{f}\)

4. Piecewise polynomial：Splines

  • Process: choose knots → use piecewise (often cubic) polynomials → enforce interpolation + smoothness (C1/C2) → solve a linear system for coefficients.
  • 一种局部准确的拟合
  • Cubic spline (piecewise definition of local segments)
\[S(x)=S_i(x),\quad x\in[x_i,x_{i+1}],\]
\[\quad S_i(x)=a_i+b_i(x-x_i)+c_i(x-x_i)^2+d_i(x-x_i)^3\]
  • Smoothness constraints (connection)
\[S_i(x_i)=y_i,\quad S_{i}(x_{i+1})=S_{i+1}(x_{i+1})\]
\[S_i'(x_{i+1})=S_{i+1}'(x_{i+1}),\]
\[S_i''(x_{i+1})=S_{i+1}''(x_{i+1})\]
